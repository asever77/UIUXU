Accordion

Accordion 컴포넌트는 접을 수 있는 콘텐츠 패널을 표시하는 접근성 좋고 유연한 방법을 제공합니다.
이를 통해 사용자는 콘텐츠 섹션을 표시하거나 숨길 수 있어 FAQ, 제품 상세 정보 또는 정보가 효율적으로 구성되어야 하는 모든 시나리오에 이상적입니다.

Example 1: 자동 초기화 (JS 작성 필요 없음)

마크업에 data-ui="accordion"만 부여하면 UX.init() 시 자동으로 아코디언이 구동됩니다.

JS 작성 없이 data-ui="accordion"으로 자동 작동됩니다.

자동 아코디언 항목 2의 내용입니다.

Example 2: 커스텀 수동 세팅 (특수 옵션 적용)

초기열림(expanded), 다중열기(singleOpen: false), 스크롤 이동(scrollIntoView) 등 커스텀 옵션이 필요할 때 JS 코드로 세팅합니다.

expanded: "accoCustom-0" 옵션에 의해 시작 시 자동으로 열려 있습니다.

singleOpen: false 옵션 덕분에 1번과 2번이 동시에 열려 있을 수 있습니다.

Example 3: 복합 헤더 (체크박스/링크) 및 중첩 아코디언 (Nested)

이벤트 위임과 Sibling Flex 레이아웃을 적용하여 헤더에 체크박스/링크가 들어있어도 독립적으로 동작하며, 중첩 아코디언 간 간섭을 방지합니다.

관련 링크

상위 아코디언 내부입니다. 아래에 하위 중첩 아코디언이 포함되어 있습니다.

하위 아코디언 1-1의 독립된 세부 내용입니다. 상위 아코디언을 건드리지 않고 개별 토글됩니다.

Code

HTML


<div data-accordion="name">
	// 아코디언 항목
	<div data-accordion-item>
		// 아코디언 헤더 (Sibling Flex 구조)
		<div data-accordion-head>
			<label><input type="checkbox" /> 선택</label>
			<h3 data-accordion-title>
				<button type="button" data-accordion-button>제목 텍스트</button>
			</h3>
			<a href="#">외부 링크</a>
		</div>
		// 아코디언 내용
		<div data-accordion-body hidden>
			<div data-accordion-section>
				...
			</div>
		</div>
	</div>
</div>

javascript


<script type="module">
	import Accordion from './component/accordion.js';

	const acco1 = new Accordion({
		id: 'acco1',
		expanded: null,
		singleOpen: true,
		scrollIntoView: true,
		scrollOptions: { 
			behavior: 'smooth', 
			block: 'nearest' 
		},
	});

	// 초기화 (이벤트 위임 적용으로 동적 항목 추가 시 별도 update 불필요)
	acco1.init(); 
	// 프로그램 방식 조작
	acco1.show('acco1-0');
	acco1.hide('acco1-0'); 
	// 리소스 정리
	acco1.destroy();
</script>

Options

Accordion 클래스 생성자에 전달할 수 있는 옵션에 대한 상세 명세입니다.

옵션명 타입 기본값 설명
id String 필수 아코디언 인스턴스의 고유 식별자입니다. 주 컨테이너의 data-accordion 속성과 일치해야 합니다.
expanded string 또는 null null 로드 시 기본적으로 열어둘 아코디언 버튼의 ID 또는 인덱스 값을 지정합니다.
singleOpen boolean true 한 번에 하나의 아코디언만 열 것인지(true), 다중 열기를 허용할 것인지(false) 결정합니다.
scrollIntoView boolean false 열릴 때 해당 아코디언 항목 위치로 부드럽게 스크롤 보정을 실행할지 여부입니다.
scrollOptions object { behavior: 'smooth', block: 'nearest' } scrollIntoView 동작 시 사용할 ScrollIntoViewOptions 객체입니다.

Accessibility

제목 태그와 버튼 역할의 적절한 분리 (WCAG 2.1)

헤더 영역 내에 체크박스나 링크가 포함될 경우, 절대 위치 Overlay 버튼 사용을 지양하고 Sibling Flex 구조로 마크업합니다. 이를 통해 스크린 리더와 키보드가 각 요소로 정확히 포커스 이동할 수 있습니다.

  • KWCAG 2.2 제목 제공 및 WCAG 2.1 Info and Relationships (A)
  • Interactive Content 중첩 오류 방지 (<button> 내부 <a>, <input> 금지)

WAI-ARIA 1.2 Accordion Pattern 완벽 지원

버튼에는 aria-expanded와 aria-controls를, 콘텐츠 영역에는 role="region"과 aria-labelledby를 자동으로 연결해 스크린 리더에서 상태 조작 및 관계를 인지할 수 있습니다.

  • WCAG 2.1 Name, Role, Value (A)

키보드 탐색 및 중첩 보장 (ArrowNavigator)

방향키(Up/Down)로 아코디언 헤더 간 포커스를 손쉽게 이동할 수 있으며, 중첩 아코디언 환경에서도 직계 부모 관계를 검증하여 독립적인 조작을 보장합니다.

  • WCAG 2.1 Keyboard Accessible (A)
