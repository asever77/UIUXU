설정 항목 React / Vue Prop HTML data-* Attribute 설명 및 허용 값
레이어 종류 type="dropdown" data-ui-layer="dropdown" dropdown, tooltip, modal, toast 선택
위치 (Placement) placement="bottom-start" data-ui-placement="bottom-start" top, bottom, left, right, bottom-start, auto
트리거 이벤트 trigger="click" data-ui-trigger="click" click, hover, focus, manual
Z-Index 그룹 zIndexGroup="modal" data-ui-z-index="modal" tooltip(1000), dropdown(2000), modal(3000), toast(4000)
상태 표시 (JS자동) state="open" data-ui-state="open" Tailwind CSS data-[ui-state=open]:... 바인딩
